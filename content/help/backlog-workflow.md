# Working with a backlog

Open a repository to see its epics, features and stories. The repository name stays visible above the backlog. Use **Add Epic**, **+ Feature** or **+ Story**; the dialog shows the repository and parent under which the new item will be created.

Every field has a persistent label. Tab moves through the form, Enter on **Create** submits it, and Escape dismisses it when no request is pending. Creation disables repeat submissions. If it fails, the dialog keeps your text and explains the failure so you can retry.

Each story has labeled agent-rule and status selectors. Failed changes retain the previous value. **Refine** starts refinement in the current repository; **Refresh** checks the result. Expand the refinement result to read the description, acceptance criteria, risks and test plan. Refreshing does not cancel the remote run.

Use **Retry** after a backlog loading failure. At narrow widths, controls wrap and the navigation menu supports keyboard focus and Escape. The theme toggle switches between light and dark and remembers your preference.
